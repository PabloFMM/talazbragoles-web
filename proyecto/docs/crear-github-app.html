Crear la GitHub App de Hermes

  1. Inicia sesión en GitHub con la cuenta PabloFMM en este navegador.
  2. Pulsa el botón. GitHub te pedirá confirmar el nombre de la app: pulsa Create GitHub App.
  3. GitHub te llevará a la página del repo con ?code=… en la dirección. Copia esa dirección entera y pégasela a Hermes en el chat antes de 1 hora (el código caduca).
  4. Después, en la página de la app, pulsa Install App → Only select repositories → talazbragoles-web → Install.

El código no es una contraseña: solo sirve una vez para que Hermes recoja la clave de la app y la guarde fuera del repo.
